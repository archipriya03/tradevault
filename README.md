# TradeVault 📈

A full-stack stock trading platform built with React, Node.js, MongoDB and JWT authentication.

## Live Demo
- Frontend: https://tradevault-frontend-1nz2.onrender.com
- Dashboard: https://tradevault-dashboard.onrender.com

## Features
- JWT Authentication with Role Based Access Control (RBAC)
- Buy/Sell orders with real-time portfolio tracking
- Holdings, Positions and Orders dashboard
- Protected routes — unauthorized users redirected to login
- Per-user data — each user sees only their own portfolio

## Tech Stack
- Frontend: React.js, React Router
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Auth: JWT, bcryptjs
- Deployment: Render

## Setup
cd backend && npm install && npm start
cd frontend && npm install && npm start
cd dashboard && npm install && npm start
